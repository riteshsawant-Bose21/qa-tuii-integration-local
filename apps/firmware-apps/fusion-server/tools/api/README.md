# Bruno API data

## Setup

- Import the Bruno collection into Bruno.
- Create your own environment files.
  - By default, only two environment files are git tracked: **local** and **multipass**.

## Important Note

If you plan to modify the collection, be careful *not to push unintended changes* to Git.

- Any modification, including changes to an API request body, is treated as a change to that API.
- Only push updates that are useful and relevant to all users.
